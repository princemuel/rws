# Websockets

This is my naive implementation of the websocket protocol in Rust for learning purposes.


## Relevant RFCs

- [RFC 6455: The WebSocket Protocol](https://www.rfc-editor.org/info/rfc6455)
- [RFC 7936: Clarifying Registry Procedures for the WebSocket Subprotocol Name Registry](https://www.rfc-editor.org/info/rfc7936/)
- [RFC 8307: Well-Known URIs for the WebSocket Protocol](https://www.rfc-editor.org/info/rfc8307/)
- [RFC 8441: Bootstrapping WebSockets with HTTP/2](https://www.rfc-editor.org/info/rfc8441/)
